# Fox (fox.glb)

Khronos glTF-Sample-Assets の `Models/Fox` を元に、Walk のクリップの b_Root_00 に前へ進む移動 (130 cm/秒) を足したもの
(`examples/anim_events/tools/bake_root_motion.py` で作る)。それ以外は元のまま。
