# Sponza — クレジット

- モデル: Crytek Sponza (Sponza Atrium)
- 原作者: Frank Meinl (Crytek)
- ライセンス: CC BY 3.0 (<https://creativecommons.org/licenses/by/3.0/>)
- 入手元: <https://casual-effects.com/data/> (McGuire Computer Graphics Archive) の
  "fixed" 版 OBJ。テクスチャを縮小 (最大 1024px) して glTF (sponza.gltf +
  sponza.bin) へ変換したものを同梱している。ジオメトリ・テクスチャの内容は
  原版のまま。実行時の LOD 変換キャッシュ (sponza.gltf.clod) はエンジンが
  初回に自動生成する。
