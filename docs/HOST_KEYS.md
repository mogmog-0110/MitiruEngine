# host が使うキー

`mitiru_host` は F1 と F7〜F12 を自分の操作に使う。ゲームの窓が前面にある間はいつでも効き、`mitiru run` で起動したときも、`mitiru dist` で配った物でも同じに効く。

| キー | host がすること |
|---|---|
| F1 | デバッグメニューを開閉する (パッドは左右のスティックの押し込み)。ゲームの項目と、下の F7〜F12 と同じ操作が並ぶ。[DEBUG_MENU.md](DEBUG_MENU.md) |
| F7 | 止めている間に 1 フレームだけ進める |
| F8 | 止める / 動かすを切り替える (update の dt が 0 になる。描画は続く) |
| F9 | 時間の速さを 1 → 0.5 → 0.25 → 2 → 4 → 1 倍の順に切り替える |
| F10 | ローファイの後処理 (DX12) を切り替える |
| F11 | 直前の入力の記録 (バグの再現用) を .mtrr に保存する |
| F12 | 画面を `screenshots/frame_*.png` に保存し、クリップボードにも写す |

カットシーンの間 (`hud.cinematic`) は F7・F8・F9 が効かない。

F1 はメニューが受けるので、ゲームには届かない。F7〜F12 はゲームにも届く。`in.pressed(Key::F9)` でロードを書くと、ロードと同時に時間の速さも変わる。ゲームの操作には F1〜F6 か、ほかのキーを使う。セーブとロードなら F5 と F6 にする。

host は実際のキーボードを読む。入力の台本 (`--input-script`) や録画の再生で流した F7〜F12 はゲームにだけ届き、host の操作は起きない。

host のキーは Windows だけで効く。一覧は `mitiru_host --help-all` でも出る。

Alt+Enter は枠なし全画面とウィンドウを切り替える。開発用のキーではないので、下の方法で切っても効く。この Enter はゲームにも UI の選んでいる項目にも届かない。ウィンドウの形は `settings.json` の `graphics.windowMode` に残る ([SAVE_AND_SETTINGS.md](SAVE_AND_SETTINGS.md))。人が遊ぶ起動だけで効き、スクリプトや録画の再生では効かない。

## 配布版で切る

F1 のデバッグメニューと F7〜F12 は、次のどれか 1 つで **まとめて** 切れる (どれか 1 つでも切ると言えば切れる)。切ると、F1 は何も起きず、メニューの画面も組み込まない。

| 出どころ | 書き方 | F12 を残す |
|---|---|---|
| 起動の引数 (`launch.mtargs` にも書ける) | `--no-dev-keys` | `--screenshot-key` を足す |
| DLL の隣の `ship.json` | `"devKeys": false` | `"screenshotKey": true` |
| ゲームの申告 | `MITIRU_DEBUG_MENU` の関数で `m.devToolsOff(true)` | `m.devToolsOff(true, /*keepScreenshotKey=*/true)` |

ゲームの申告は動的で、ゲーム自身の設定ファイル (提出版かどうかのフラグなど) をそのまま映せる。ゲームは自分の開発用のキーを切る設定と同じ値を申告すれば、設定の置き場所が 1 つで済む。
host は切った理由を `--verbose` で 1 度だけ知らせる。F12 だけは、どれかが残すと言えば、切っていても効く。
