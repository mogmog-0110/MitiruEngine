チュートリアル

小さなものを実際につくって、エンジンの考えかたを覚えるためのページ。

このページで分かること

  • MitiruEngine で実際に作るチュートリアル一覧
  • どこから読めばいいか
  • 関連ページへのリンク

「動かすところまでは はじめに で済んだので、何かつくってみたい」というひと向けです。

短めのチュートリアルを 3 本用意しています。順番に縛られません。あなたが作りたいゲームに近いものから始めて OK です。アクションが作りたいなら 02 から、セーブだけ気になるなら 03 から読んでも問題ありません。

それぞれ 15 〜 30 分くらいで、手元で動くところまで行きます。エンジンの考えかた (C++ で状態を持つ / HTML で見た目をつくる / 必要なときだけ薄い信号でつなぐ) はどのレッスンでも同じです。

レッスン一覧

01

1 シーンに文字を出す

15 〜 20 分

背景の上にテキスト UI を出して、クリックで次のメッセージへ進む。 アクションのカットシーン、RPG の村人会話、シミュレーションのイベント通知、 シューティング合間の連絡まで、どのジャンルでも出てくる「画面に何かを出す」の基礎です。

02

2D アクションのプロトタイプ

20 〜 30 分

矩形プレイヤーを矢印キー / WASD で動かす。壁との当たり判定と、 画面上の小さな目標 (拾うと得点) を入れる。 `mitiru.input` のアクションマップを使ったキー入力と canvas 描画の基本が分かります。

03

セーブとロード

20 〜 30 分

HP / スコア / 進行度を JSON に書き出して、次の起動で復元。 `SaveSchema` と `MigrationChain` を使うと、後でセーブの形を変えても 古いセーブが壊れずに読めます。ジャンルを問わず必要になる仕組みです。

どこから読めばいいか

  • エンジンの考え方をひととおり知りたい ⇒ 01 → 02 → 03 の順で全部やるのがいちばん早いです。1 時間ちょっとで終わります。
  • 作りたいゲームのジャンルが決まっている ⇒ 一番近いものから始めて OK。たとえばパズルやアクションなら 02 から。ストーリーや会話を見せたいなら 01 から。
  • エンジン自体に興味がある ⇒ チュートリアルは飛ばして API・アーキテクチャ を直接読むのもありです。

途中で「これ違くない?」「説明が足りない」と思ったら、Issue で教えてください。
