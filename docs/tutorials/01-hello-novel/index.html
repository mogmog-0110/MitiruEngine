01 1 シーンに文字を出す

このチュートリアルでは、こんな画面を動かすところまで行きます。

  • 1 枚の背景
  • 画面の下にテキストボックス
  • クリック (またはスペース) で次のテキストへ
  • 最後に「OK」と出る

時間の目安は 15 〜 20 分。ビルドの待ち時間込みです。

これは「会話シーンを作るためのチュートリアル」ではありません。画面に何かを出して、クリックで進める、というあらゆるジャンルで出てくる基本を、いちばん短く書いたものです。最後のセクションで、同じ仕組みが他ジャンルでどう使えるかも書いておきます。

事前に はじめに を済ませて、ビルドが通ることを確認しておいてください。サンプル一式は Round 39 で刷新中です。

全体の構成

MitiruEngine の流儀では、こんなふうに役割を分けます。

やることどこに書く
メッセージのデータ (本文、順序)JSON ファイル
シーンの進行・状態C++
画面 (背景、テキストボックス、ボタン)HTML + CSS
C++ と HTML のあいだsignal-only bridge (cefQuery / executeJavaScript)

「データは JSON」「ロジックは C++」「見た目は Web の道具」。この 3 つを覚えておけば迷いません。

手順 1: データを書く

my_first_scene/messages.json を新規作成して、こんな内容を書きます。

{
  "messages": [
    { "speaker": "システム", "text": "ようこそ。これは最初のシーンです。" },
    { "speaker": "システム", "text": "クリック (またはスペース) で次に進みます。" },
    { "speaker": "プレイヤー", "text": "ふむふむ、シンプルだ。" },
    { "speaker": null,       "text": "—— こうして、はじめの一歩が踏み出される。" }
  ]
}

speaker が null のときは話し手の名前を出さない、ただのメッセージとして表示します。配列にしてあるだけで形式の自由度は高いので、後でクエストログでも、ヒント表示でも、戦闘ログでも使い回せます。

手順 2: メッセージを進める C++ を書く

my_first_scene/main.cpp を作って、JSON を読んで「いま何行目か」を覚える小さな状態機械を書きます。

#include <fstream>
#include <mitiru/Mitiru.hpp>
#include <nlohmann/json.hpp>

using json = nlohmann::json;

class HelloScene final : public mitiru::Game {
public:
  mitiru::Size layout(int w, int h) override { return {w, h}; }

  void onStart() override {
    std::ifstream in("messages.json");
    in >> m_script;
    m_messages = m_script["messages"];
    pushMessageToView();
  }

  void update(float dt) override {
    if (hasInput() && input().isMouseJustPressed(mitiru::MouseButton::Left)) {
      advance();
    }
  }

  void draw(mitiru::Screen&) override {
    // 描画は HTML 側がやる。C++ 側は状態管理に集中する。
  }

private:
  void advance() {
    ++m_index;
    if (m_index >= m_messages.size()) {
      pushEndToView();
    } else {
      pushMessageToView();
    }
  }

  void pushMessageToView() {
    auto& m = m_messages[m_index];
    char js[512];
    std::snprintf(js, sizeof(js),
      "window.showMessage && window.showMessage(%s, %s);",
      m["speaker"].is_null()
        ? "null"
        : ("\"" + m["speaker"].get<std::string>() + "\"").c_str(),
      ("\"" + m["text"].get<std::string>() + "\"").c_str());
    if (engine() && engine()->cefContext()) {
      engine()->cefContext()->executeJavaScript(js);
    }
  }

  void pushEndToView() {
    if (engine() && engine()->cefContext()) {
      engine()->cefContext()->executeJavaScript("window.showEnd && window.showEnd();");
    }
  }

  json m_script;
  json m_messages;
  size_t m_index = 0;
};

int main() {
  mitiru::Engine engine;
  HelloScene game;

  mitiru::EngineConfig cfg;
  cfg.title = "Hello Scene";
  cfg.windowWidth = 1280;
  cfg.windowHeight = 720;
  cfg.cefStartUrl = "file:///" __FILE__ "/../view.html";

  engine.run(game, cfg);
}

ポイント:

  • C++ 側は 「いま何番目のメッセージか」だけ覚える。描画はしません。
  • 進めるのも C++ 側。input().isMouseJustPressed(...) で 1 行進めます。
  • 1 行進むたびに executeJavaScript で HTML 側に通知 します。これが「C++ → JS」の signal-only bridge です。

手順 3: 見た目を HTML / CSS で書く

my_first_scene/view.html を作ります。テキストボックスを出すだけのページです。

<!DOCTYPE html>
<html lang="ja">
<head>
  <meta charset="utf-8">
  <style>
    html, body { margin: 0; height: 100%; font-family: "Noto Sans JP", sans-serif; }
    body {
      background:
        radial-gradient(circle at 30% 30%, #2a3550, #0f1426 75%);
      color: #fff;
    }
    .stage {
      position: fixed; inset: 0;
      display: flex; align-items: center; justify-content: center;
      font-size: 18px; opacity: 0.6;
    }
    .message {
      position: fixed; left: 4%; right: 4%; bottom: 4%;
      padding: 24px 28px; min-height: 110px;
      background: rgba(8, 12, 24, 0.86); border: 1px solid rgba(255,255,255,0.4);
      border-radius: 10px; box-shadow: 0 8px 24px rgba(0,0,0,0.4);
    }
    .message__name {
      display: inline-block; padding: 4px 12px;
      background: #5b8ee2; border-radius: 4px; margin-bottom: 12px;
      font-weight: 700;
    }
    .message__text { font-size: 22px; line-height: 1.55; }
    .end { font-size: 56px; text-align: center; padding-top: 35vh; opacity: 0.85; }
  </style>
</head>
<body>
  <div class="stage">— hello scene —</div>
  <div class="message" id="message">
    <div class="message__name" id="name">システム</div>
    <div class="message__text" id="text">…</div>
  </div>

  <script>
    window.showMessage = function (speaker, text) {
      var nameEl = document.getElementById('name');
      var textEl = document.getElementById('text');
      if (speaker) {
        nameEl.textContent = speaker;
        nameEl.style.display = 'inline-block';
      } else {
        nameEl.style.display = 'none';
      }
      textEl.textContent = text;
    };

    window.showEnd = function () {
      document.body.innerHTML = '<div class="end">OK</div>';
    };
  </script>
</body>
</html>

ポイント:

  • HTML 側は 「描く」「ボタン的なクリックを受ける」だけ。状態は持ちません。
  • C++ から呼ばれた window.showMessage(...) で表示を差し替えるだけ。
  • 「次へ進む」は C++ 側が決めているので、HTML 側に分岐ロジックは要らない。

手順 4: CMake に登録してビルド

examples/CMakeLists.txt に 1 行追加します。

add_subdirectory(my_first_scene)

そして my_first_scene/CMakeLists.txt。CEF を使うので mitiru_add_cef_game を呼びます。

add_executable(my_first_scene main.cpp)
target_link_libraries(my_first_scene PRIVATE Mitiru::mitiru)

include("${CMAKE_SOURCE_DIR}/cmake/MitiruCef.cmake")
mitiru_add_cef_game(my_first_scene)

# messages.json と view.html を exe の隣にコピー
file(COPY messages.json view.html DESTINATION ${CMAKE_CURRENT_BINARY_DIR})

あとはビルド。

cmake --build build --config Debug --target my_first_scene
./build/examples/my_first_scene/Debug/my_first_scene

クリックでメッセージが進んで、最後に OK が出れば完成です。

何が分かったか

  • C++ は状態の本体、HTML は表示 という分担が、実コードで体感できたはず。
  • executeJavaScript で 「これを表示して」だけ伝える ので、コードがあちこちに散らかりません。
  • データが JSON なので、テキストの書き換えは C++ をビルドしなくてもできます。

同じ仕組みは他ジャンルにも使える

ここで作ったものは「画面の上にテキスト UI を出して、何かをきっかけに次へ進む」という汎用の型です。たとえば:

  • アクションゲーム: ステージ開始のメッセージ、ボス前のカットイン、ゲームオーバー時の演出。
  • RPG: 村人 NPC との会話、クエスト授受、宿屋で休んだあとの「翌朝になった」表示。
  • シミュレーション: イベント通知、四半期決算メッセージ、ランダムイベントの選択肢提示。
  • シューティング / RTS: 出撃前のミッションブリーフィング、戦況の合間に入る無線連絡、リザルト画面。
  • パズル / カジュアル: チュートリアルのヒント、ステージクリア時のコメント、デイリーミッションの説明。

進める条件を変える (時間経過、ボタン、特定の条件) のも、C++ 側の update() を書き換えるだけです。テキストの中身もデータ側で差し替えれば再利用できます。

次の一歩

  • 背景画像をちゃんと表示する (<img> か CSS の background-image で OK)。トランジションを当てるとそれっぽくなります。
  • 選択肢を入れる。choices: [{text, action}] をデータに追加して、JS 側でボタンを描き、cefQuery で C++ に「どれを選んだか」を通知すれば動きます。これが「JS → C++」の signal-only bridge です。
  • 次のレッスン: 02 — 2D アクションのプロトタイプ に進むと、キーボード入力で動くプレイヤーが書けるようになります。
