01 会話シーンのワンシーンを動かす

このチュートリアルでは、こんな画面を動かすところまで行きます。

  • 背景画像
  • キャラクターの立ち絵
  • 下に台詞ボックス
  • クリック (またはスペース) で次の台詞へ
  • 最後に「END」と出る

時間の目安は 15 〜 20 分。ビルドの待ち時間込みです。

事前に はじめに を済ませて、./build/examples/hello_sprite/Debug/mitiru_hello_sprite が動くことを確認しておいてください。

全体の構成

MitiruEngine の流儀では、こんなふうに役割を分けます。

やること どこに書く
シナリオ (台詞、分岐) JSON ファイル
シーンの進行・状態 C++
画面 (背景、立ち絵、台詞ボックス) HTML + CSS
C++ と HTML のあいだ signal-only bridge (cefQuery / executeJavaScript)

「シナリオ駆動」「ロジックは C++」「見た目は Web の道具」。この 3 つを覚えておけば迷いません。

手順 1: シナリオを書く

my_first_vn/scenario.json を新規作成して、こんな内容を書きます。

{
  "scenes": [
    {
      "id": "school",
      "background": "school.jpg",
      "lines": [
        { "speaker": "サクラ", "text": "おはよう。今日もいい天気だね。" },
        { "speaker": "サクラ", "text": "放課後、一緒に帰らない?" },
        { "speaker": "ぼく",   "text": "うん、いいよ。" },
        { "speaker": null,    "text": "—— こうして、物語は動き始める。" }
      ]
    }
  ]
}

speaker が null のときは地の文 (ナレーション)。これだけです。

手順 2: シナリオを読む C++ を書く

my_first_vn/main.cpp を作って、JSON を読んで「いま何行目か」を覚える小さな状態機械を書きます。

#include <fstream>
#include <mitiru/Mitiru.hpp>
#include <nlohmann/json.hpp>

using json = nlohmann::json;

class HelloNovel final : public mitiru::Game {
public:
  mitiru::Size layout(int w, int h) override { return {w, h}; }

  void onStart() override {
    std::ifstream in("scenario.json");
    in >> m_script;
    m_lines = m_script["scenes"][0]["lines"];
    pushLineToView();
  }

  void update(float dt) override {
    if (hasInput() && input().isMouseJustPressed(mitiru::MouseButton::Left)) {
      advance();
    }
  }

  void draw(mitiru::Screen&) override {
    // 描画は HTML 側がやる。C++ 側は状態管理に集中する。
  }

private:
  void advance() {
    ++m_index;
    if (m_index >= m_lines.size()) {
      pushEndToView();
    } else {
      pushLineToView();
    }
  }

  void pushLineToView() {
    auto& line = m_lines[m_index];
    char js[512];
    std::snprintf(js, sizeof(js),
      "window.showLine && window.showLine(%s, %s);",
      line["speaker"].is_null()
        ? "null"
        : ("\"" + line["speaker"].get<std::string>() + "\"").c_str(),
      ("\"" + line["text"].get<std::string>() + "\"").c_str());
    if (engine() && engine()->cefContext()) {
      engine()->cefContext()->executeJavaScript(js);
    }
  }

  void pushEndToView() {
    if (engine() && engine()->cefContext()) {
      engine()->cefContext()->executeJavaScript("window.showEnd && window.showEnd();");
    }
  }

  json m_script;
  json m_lines;
  size_t m_index = 0;
};

int main() {
  mitiru::Engine engine;
  HelloNovel game;

  mitiru::EngineConfig cfg;
  cfg.title = "Hello Novel";
  cfg.windowWidth = 1280;
  cfg.windowHeight = 720;
  cfg.cefStartUrl = "file:///" __FILE__ "/../view.html";

  engine.run(game, cfg);
}

ポイント:

  • C++ 側は 「いま何番目の台詞か」だけ覚える。描画はしません。
  • 進めるのも C++ 側。input().isMouseJustPressed(...) で 1 行進めます。
  • 1 行進むたびに executeJavaScript で HTML 側に通知 します。

手順 3: 見た目を HTML / CSS で書く

my_first_vn/view.html を作ります。台詞ボックスとキャラを描く、ただの Web ページです。

<!DOCTYPE html>
<html lang="ja">
<head>
  <meta charset="utf-8">
  <style>
    html, body { margin: 0; height: 100%; font-family: "Noto Sans JP", sans-serif; }
    body {
      background: url("school.jpg") center / cover no-repeat #1a2030;
      color: #fff;
    }
    .character {
      position: fixed; bottom: 18%; left: 50%; transform: translateX(-50%);
      width: 220px; height: 380px; background: rgba(120, 140, 200, 0.55);
      border-radius: 12px;
    }
    .dialog {
      position: fixed; left: 4%; right: 4%; bottom: 4%;
      padding: 24px 28px; min-height: 110px;
      background: rgba(8, 12, 24, 0.86); border: 1px solid rgba(255,255,255,0.4);
      border-radius: 10px; box-shadow: 0 8px 24px rgba(0,0,0,0.4);
    }
    .dialog__name {
      display: inline-block; padding: 4px 12px;
      background: #e25b6c; border-radius: 4px; margin-bottom: 12px;
      font-weight: 700;
    }
    .dialog__text { font-size: 22px; line-height: 1.55; }
    .end { font-size: 56px; text-align: center; padding-top: 35vh; opacity: 0.85; }
  </style>
</head>
<body>
  <div class="character"></div>
  <div class="dialog" id="dialog">
    <div class="dialog__name" id="name">サクラ</div>
    <div class="dialog__text" id="text">…</div>
  </div>

  <script>
    window.showLine = function (speaker, text) {
      var nameEl = document.getElementById('name');
      var textEl = document.getElementById('text');
      if (speaker) {
        nameEl.textContent = speaker;
        nameEl.style.display = 'inline-block';
      } else {
        nameEl.style.display = 'none';
      }
      textEl.textContent = text;
    };

    window.showEnd = function () {
      document.body.innerHTML = '<div class="end">END</div>';
    };
  </script>
</body>
</html>

ポイント:

  • HTML 側は 「描く」「ボタン的なクリックを受ける」だけ。状態は持ちません。
  • C++ から呼ばれた window.showLine(...) で台詞を差し替えるだけ。
  • 「次へ進む」は C++ 側が決めているので、HTML 側に分岐ロジックは要らない。

手順 4: CMake に登録してビルド

examples/CMakeLists.txt に 1 行追加します。

add_subdirectory(my_first_vn)

そして my_first_vn/CMakeLists.txt。CEF を使うので mitiru_add_cef_game を呼びます。

add_executable(my_first_vn main.cpp)
target_link_libraries(my_first_vn PRIVATE Mitiru::mitiru)

include("${CMAKE_SOURCE_DIR}/cmake/MitiruCef.cmake")
mitiru_add_cef_game(my_first_vn)

# scenario.json と view.html を exe の隣にコピー
file(COPY scenario.json view.html DESTINATION ${CMAKE_CURRENT_BINARY_DIR})

あとはビルド。

cmake --build build --config Debug --target my_first_vn
./build/examples/my_first_vn/Debug/my_first_vn

クリックで台詞が進んで、最後に END が出れば完成です。

何が分かったか

  • C++ は状態の本体、HTML は表示 という分担が、実コードで体感できたはず。
  • executeJavaScript で 「これを表示して」だけ伝える ので、コードがあちこちに散らかりません。
  • シナリオが JSON なので、ライターさんは C++ を触らずに台詞を書けます。

次の一歩

  • 立ち絵をちゃんと表示する (<img> で OK)。立ち絵の出入りに CSS トランジションを当てると、それっぽくなります。
  • 分岐 (選択肢) を入れる。choices: [{text, goto}] をシナリオに追加して、JS 側でボタンを描き、C++ に通知すれば動きます。
  • 会話シーンが一通り書けたら、次は サンプル一覧 で vn_hello_world や vn_game_hybrid を読んでみてください。同じ考え方を実例で確認できます。同じ仕組みでアクションのカットシーン、RPG のクエスト進行、シミュレーションのイベントトリガーも書けます。
