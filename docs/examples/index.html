サンプル

examples/ 配下のサンプルは、すべて標準の CMake プリセットでビルドできます。スクリーンショットつきは実画面が出るもの、それ以外はコンソール出力で挙動を確認するタイプです。エンジンは特定ジャンルに寄せた設計ではないので、ここに並ぶ各サンプルは「エンジンのどの部品がどう使えるか」を示すものとして読んでください。気になったものを動かして、main.cpp を読むのがおすすめです。
