# RML のルビ (`<ruby>`)

画面の字を RmlUi で出すときに、親文字の上へルビを置く。設計と捨てた案は ADR 0131。
`Screen::drawTextRuby` (ADR 0112) は C++ で描く文字用で、RML の文字には届かない。RML では下の要素を使う。

```html
<link type="text/rcss" href="mitiru:base.rcss"/>
...
吾輩は<ruby>猫<rt>ねこ</rt></ruby>である。
<phrase>吾輩は<ruby>猫<rt>ねこ</rt></ruby>である。名前はまだ無い。</phrase>
```

使わない RML には何も起きない。`<ruby>` を書いた文書だけ、`base.rcss` の 3 つの規則 (`ruby` / `rt` / `rp`) と `RubyElement` が働く。

## 組み方

| 場面 | 結果 |
|---|---|
| 箱の幅 | 親文字とルビの長い方 (`ruby` が inline-block で shrink-to-fit) |
| ルビが親文字より短い | 字を均等に割り付ける。余りは各字の前後へ半分ずつ (`drawTextRuby` と同じ) |
| ルビが親文字より長い | 箱が広がり、隣の字を押す。親文字は中央 |
| 行の高さ | ルビは行間の余りに先に入り、足りない分だけ行が高くなる (`line-height: 1.2` の 20px の文字で、ルビ付きの行は 9px 高い。`line-height: 44px` の行は余りが足りるので変わらない)。ルビの無い行は変わらない |
| 基線 | 親文字が隣の字と同じ基線に載る |
| 折り返し | `ruby` は 1 つの塊 (`white-space: nowrap`)。親文字とルビの途中では割れず、前後だけが折れ目 |
| `<phrase>` の中 | `<ruby>` は元の位置に残り、その前後の文字が別々に文節へ置き直される。ルビの前後は折れ目になるので、行末の位置によっては「生」と「れ」の間で折れる (既知の制限) |
| 読みに ASCII を含む | 割らず、中央に 1 かたまり |
| 2 つ目の `<rt>` | 出さずに警告を 1 度ログへ出す。1 組ごとに `<ruby>` を分ける |

ルビは親の 0.5 倍の大きさ。縁取り (`font-effect`) は親から受け継ぐので、太い縁取りの所は `rt` に細い縁取りか `none` を書く。

```css
rt { font-size: 0.6em; font-effect: outline(2px #10121c); }
```

## 読み上げ

名前に入るのは親文字だけ。`rt` と `rp` は読み上げの木から外れる (読み上げソフトが漢字を自分で読むので、読みを足すと 2 度読まれる)。
ふりがなを聞かせたいときは、要素の `aria-label` に自分で書く。

## OOZE DRIVE の置き換え手順

1. エンジンを、この要素の入ったバージョンに上げる。
2. `assets/ui/*.rml` の `<link ... href="ruby.rcss"/>` を外し、`assets/ui/ruby.rcss` を消す。残すと古い `rt { position: absolute; left: -100%; right: -100% }` が新しい `rt` にも当たり、ルビの字が親文字の 3 倍の幅に散る (撮って確かめた)。1 と 2 は同じコミットにする。
3. `ruby.rcss` にあった `rt { font-effect: outline(2px var(--ink)) }` と、バンドの上で縁取りを切る `.set-row.on rt { font-effect: none }` などの行は、ゲームの RCSS に残す (縁取りはゲームの見た目の都合)。
4. `src/text/RubyRml.hpp` (文の ｜親《るび》 → `<ruby>`) は消さない。出す `<ruby>親<rt>るび</rt></ruby>` はそのままエンジンの要素に載る。記法の変換をエンジンに移すのは別の仕事 (ADR 0131 の最後)。
5. ルビ付きの行は行間の余りで足りない分だけ高くなる。固定の高さの枠 (`height:` を数値で書いた所) は、撮って確かめる。
6. エンジンは `rt` の字を 1 字ずつ `span` にする。ゲームの RCSS に `.foo span { ... }` のような子孫セレクターがあると、`rt` の字にも当たり、ルビが本文と同じ大きさで散る (OOZE DRIVE の案内で起きた)。`.foo > span` の子セレクターにする。
