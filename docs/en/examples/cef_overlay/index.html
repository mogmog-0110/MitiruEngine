CEF Overlay

Native DX12 scene plus a transparent CEF HTML overlay. F1 toggles input focus between CEF and the native game.

Key APIs

  • mitiru::Game (subclass with update/draw/layout)
  • mitiru::Engine + mitiru::EngineConfig
  • mitiru::core::Engine::cefContext()::setInputEnabled
  • mitiru::core::Engine::cefContext()::executeJavaScript
  • window.cefQuery JS bridge
  • Native 2D draw helpers (drawRect, drawCircle, drawRectFrame)

Native DX12 scene plus a transparent CEF HTML overlay (Phase A/B reference). The C++ side draws a time-animated background, a moving circle with a trail, and a vertical pulse bar. CEF loads assets/overlay.html on top as a HUD. Windows + CEF only.

What you’ll see

  • Animated background (slow RGB drift) with an orange circle orbiting the centre, plus a four-step alpha trail.
  • A green vertical bar in the top-left whose height pulses with sin(2t).
  • The HUD HTML overlay on top, showing the frame counter pushed from C++ and reacting to the focus toggle.
  • Press F1 to flip input focus. When native owns input, a thin green frame draws around the viewport edge.
  • Remote debugging on http://localhost:9222.

Build and run

cmake --build build --config Debug --target mitiru_cef_overlay
./build/examples/cef_overlay/Debug/mitiru_cef_overlay

mitiru_add_cef_game() copies the CEF runtime (libcef.dll, .pak, locales/, MitiruCefHelper.exe) next to the executable.

Companion examples

  • cef_minimal — UI-driven (all gameplay in JS, no native draw).
  • cef_state_bridge — same hybrid shape but with two-way StateStore sync.
  • cef_transition — transitioning between two HTML pages.
