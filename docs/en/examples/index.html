Examples

Every sample under examples/ builds with the default CMake preset and runs standalone. The CEF samples open a window and host an HTML overlay; the rest are headless console programs that print a deterministic trace to stdout.

If a card shows the placeholder image, run python tools/site/capture_examples.py from the repo root to populate site/static/screenshots/<name>.png for every example, then rebuild the site.
