# 縦書きとルビ

`drawTextVertical` に文字列を渡すと、host が縦書きに組んで描く。見本は `examples/vtext`。設計の経緯は
ADR 0111。

```cpp
s.drawTextVertical(rect, "吾輩《わがはい》は猫である。2026年、ABC。", color, 34.0f,
                   module::TextWriting::VerticalRl, /*tateChuYoko=*/true, /*padX=*/24.0f, /*padY=*/24.0f);
```

`fontSize` は横書きの `drawTextInRect` と同じ意味 (ascender から descender まで)。縦書きの 1 字分 (em) は、この書体では
`fontSize` の約 0.72 倍になる。行は rect の高さで折り返し、入りきらない行は描かない。`VerticalRl` は行が右から左へ、
`VerticalLr` は左から右へ進む。最初の行は rect の端 (Rl は右端、Lr は左端) に接する。1 行ぶんの幅に満たない rect には何も描かない。

## 字の向き

| 字 | 置き方 |
|---|---|
| 漢字・かな・全角の記号 | 立てる |
| 、。「」 と小書き仮名 (ゃ っ) | 書体の縦組み用の字形 (`vert`)。句読点と小書き仮名は右上へ寄り、括弧は縦に倒れる |
| 長音 ー と 〜 | 縦組み用の字形 (縦棒)。書体に無ければ寝かせる |
| 欧文の語 (`Mitiru`、`ABC`) | 語ごとに時計回りへ 90 度寝かせる。語の途中で折り返さない |
| 数字 2 桁と `!!` `!?` `?!` `??` | 縦中横。1 字分の中に横組みで収める (`tateChuYoko` が true のとき) |
| 数字 1 桁 | 立てる |
| 数字 3 桁以上 (`2026`) | 欧文の語と同じく寝かせる |

向きの既定は Unicode の UAX #50 (Vertical_Orientation) の値で、書体に依らない。

## 折り返し (禁則)

- 行頭に来てはいけない字 (閉じ括弧、小書き仮名、長音、中点) は、前の字を道連れにして次の行へ送る
- 行末に来てはいけない字 (開き括弧) は、次の行へ送る
- 句点と読点 (`、。，．`) だけは、行の外へ 1 字ぶら下げる
- `\n` で改行する。空の行も 1 行ぶん空ける

## ルビ

`親文字《るび》` と書く。

| 書き方 | 親文字 |
|---|---|
| `吾輩《わがはい》` | 《 の直前に続く漢字の連なり |
| `｜日本語《にほんご》` | ｜ (全角でも半角の `|` でも) から 《 の手前まで。漢字でなくてもよい |

- ルビは親文字の右 (縦書き) に、親文字の半分の大きさで置く
- ルビが親文字より短いときは、ルビの字の前後に余りを均等に配る。長いときは、親文字を同じ要領で割り付けて、組全体をルビの長さにする。
  隣の字へはみ出させない
- 漢字が前に無く ｜ も無い 《》 (書名など) は、書いたとおりに描く。閉じていない 《 も同じ

## できないこと

- 横書きのルビ (親文字の上) は組版には入っているが、ゲームから頼む入口が無い。`TextWriting` に横書きでルビを組む値を足す
  変更が要るので、ABI の次の版に回す
- 行ごとの寄せ (上寄せ・中央・下寄せ)、字間の調整、圏点 (傍点)、割注は組まない
- 組み方を選ぶのは書体の `vert` だけで、`vrt2` と `vkna` は見ない (HarfBuzz の縦書きの既定と同じ)
- 描画先が文字を回せないとき (DX11 と OpenGL の CPU 経路) は、寝かせる欧文を 1 字ずつ立てる
- 8x8 ドットの書体 (`--font none`) では縦書きにならず、横書きで描いて 1 度だけ知らせる
