COMMAND LINE INTERFACE

制作から配布まで、23のコマンドで操作する

mitiru は MitiruEngine のコマンドラインインターフェースです。プロジェクト作成、実行、検証、配布などを、役割ごとに分かれたコマンドから操作できます。

全コマンドを見る

全コマンド

引数なしで実行すると、番号で操作を選べる対話ランチャーが開きます。各コマンドのオプションは mitiru <コマンド> --help で確認できます。

コマンド役割

buildプロジェクトをビルド
runビルドして実行
watchsrc/ を監視してホットリロード

lintHTML と C++ の値の受け渡しを静的検査
verify自動実行して合否を JSON で出力
replay入力の記録、再生、回帰テスト
mcpAI からゲームを観測、操作するサーバーを起動
inspect実行中のゲームに観察用ウィンドウを接続
rendererレンダラだけを起動
input入力処理だけを起動

audioオーディオミキサーだけを起動

作成と実行

mitiru new：プロジェクトを作る

hello、clicker、shooter の3種類からテンプレートを選び、新しいプロジェクトを作ります。ゲームは DLL としてビルドされ、mitiru_host から起動されます。

mitiru new myGame
mitiru new myGame -t clicker
mitiru new myGame --force

mitiru build：ビルドする

現在または親のディレクトリから mitiru.toml を探し、指定された版のエンジンソースを ~/.mitiru/cache/ に取得して、CMake の configure と build を実行します。

mitiru build
mitiru build --release

mitiru run：ゲームを起動する

プロジェクトをビルドして起動します。観察用ウィンドウの併用、ブラウザ上の実行時パネル、入力の記録にも対応します。

mitiru run
mitiru run --inspect
mitiru run --inspect rewind
mitiru run --console
mitiru run --record session.mtrr

--inspect には perf、inspector、rewind、mixer、scene、replay、input を指定できます。

mitiru watch：変更を実行中に反映する

一度ビルドして起動した後、src/ の変更を監視します。再ビルドされた DLL はホストによって差し替えられ、ゲームの状態は差し替え後も維持されます。assets/ 内の HTML、CSS、JavaScript はエンジン側で再読み込みされます。

mitiru watch
mitiru watch --inspect rewind

mitiru debug：デバッグ設定で起動する

Debug 構成に固定し、MITIRU_DEBUG=1 と MITIRU_INSPECTOR=1 を設定して起動します。

mitiru debug

mitiru ui：画面だけを確認する

C++ をビルドせず、assets/ をローカル HTTP サーバーから配信します。window.mitiru のモック実装により、mitiru_bind.js の data-m-* バインドもブラウザ上で動作します。

mitiru ui
mitiru ui assets/hud.html
mitiru ui --state mock.json
mitiru ui --port 9000

mitiru lint：値の受け渡しを検査する

scene.html の data-m-* と C++ から送る値を照合します。C++ から送られない名前、不正なマークアップ、エンジン付属スクリプトの読み込み漏れなどを実行前に検出します。

mitiru lint
mitiru lint --strict

自動検証と観察

mitiru verify：自動実行の結果を返す

ビルド、MITIRU_AI=1 での起動、指定フレームの待機、スクリーンショット取得、終了までを自動で進め、結果を JSON で標準出力へ返します。終了コードは合格が 0、不合格が 1、ビルドエラーが 2 です。

mitiru verify
mitiru verify --golden ref.png
mitiru verify --replay session.mtrr
mitiru verify --frames 600 --json

--golden では、正解として保存した基準画像と比較します。既定の閾値は 95% です。

mitiru replay：入力を記録、再生する

入力ストリームを記録し、同じセッションをビット単位で再現します。--test --game ではウィンドウと CEF を起動せず、ゲームの最終状態を JSON で出力します。

mitiru replay --record demo.mtrr
mitiru replay --replay demo.mtrr
mitiru replay --test session.mtrr --game
mitiru replay --test s.mtrr --expect e.json

mitiru mcp：AI から操作できるようにする

stdio を使う MCP（Model Context Protocol）サーバーを起動します。AI から状態取得、差分取得、スクリーンショット、入力送信、ポーズ、1フレーム実行、時間倍率の変更、シーンツリー取得、verify の実行ができます。

ゲームは MITIRU_AI=1 で起動します。既定ポートは 8090 で、--port または MITIRU_AI_PORT から変更できます。

{"mcpServers":{"mitiru":{"command":"mitiru","args":["mcp"]}}}

mitiru inspect：実行中のゲームを観察する

実行中のゲームへ、別の OS ウィンドウとして inspector を接続します。プロセス ID を省略すると直近のゲームを自動検出します。--all では gameplay、input、rewind の3画面を開きます。

mitiru inspect
mitiru inspect 12345
mitiru inspect 12345 --inspectable rewind
mitiru inspect 12345 --all

機能別の単独起動

ゲームの処理を含めず、エンジン内の各機能を個別に起動できます。問題の発生箇所を切り分けるときにも使用できます。

mitiru renderer：描画を確認する

描画パイプラインだけを起動し、グリッドとアニメーションするテストパターンを表示します。

mitiru renderer

mitiru input：入力を確認する

キーボードとマウスの入力を取得し、エンジンがフレームごとに参照する入力を表示します。レンダラとシーン管理は起動しません。

mitiru input

mitiru scene：シーン遷移を確認する

シーンの追加、復帰、差し替えと、生成から破棄までの流れをゲームの処理なしで確認します。

mitiru scene

mitiru audio：音声機能を確認する

オーディオミキサーだけを初期化します。.wav、.mp3、.flac のパスを渡すと、起動時に読み込みます。

mitiru audio
mitiru audio bgm.mp3

配布と環境管理

mitiru dist：配布用データを作る

Release ビルドし、ホスト、ランタイム、ゲーム DLL、アセット、ダブルクリック起動用ランチャーを配布フォルダへまとめます。詳しい構成は配布ページで確認できます。

mitiru dist
mitiru dist --zip
mitiru dist --pack
mitiru dist --bat

mitiru doctor：開発環境を診断する

OS、CMake、コンパイラなど、ビルドに必要な項目を確認します。不足している項目があれば、入手方法のヒントを表示します。

mitiru doctor

mitiru clean：生成物を削除する

プロジェクトの build/ を削除します。--all を指定すると、~/.mitiru/cache/ にあるエンジンソースのキャッシュも削除します。

mitiru clean
mitiru clean --all

mitiru install：Windows をセットアップする

MSVC Build Tools の導入、mitiru.exe の配置、PATH の追加、エンジンソースの事前取得をまとめて実行します。リリース zip に含まれる MitiruEngine_Installer.exe と同じ処理です。

mitiru install
mitiru install --dry-run
mitiru install --force

mitiru update：エンジン版数を更新する

公開リポジトリの最新リリースを確認し、mitiru.toml の engine 行を更新します。マイナー以上の更新では差分を表示し、確認後に適用します。ほかの行やコメントは保持されます。

mitiru update
mitiru update --check
mitiru update --yes

mitiru self-update：CLIを更新する

mitiru.exe を最新リリースへ差し替えます。プロジェクトで使うエンジンの版数は mitiru update で更新します。

mitiru self-update
mitiru self-update --check

mitiru menu：番号から操作を選ぶ

現在の場所がプロジェクト内か外かを判定し、利用できる操作を番号付きで表示します。引数なしの mitiru と短縮形の mitiru m でも起動できます。

mitiru
mitiru menu
mitiru m

mitiru version：版数を確認する

CLI の版数とプラットフォームを表示します。

mitiru version
