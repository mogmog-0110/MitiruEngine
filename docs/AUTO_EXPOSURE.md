# 自動露出

画面の明るさを測って、露出を自動で合わせる機能です。暗い洞窟から明るい外へ出ると、一瞬白く飛んで、1 秒ほどで目が慣れます。既定は切で、入れなければ今までと同じ絵です。DX12 だけで効き、Dawn は固定の露出のままです。

## 使い方

1. `mitiru.toml` の `[render] needs` か `MITIRU_RENDER_NEEDS` に `auto_exposure` を足します。
2. ゲームの `draw` で、`SceneLook::autoExposureSpeed` に 0 より大きい値を入れて `sceneLook3D` を呼びます。

```cpp
mitiru::render::SceneLook look;
look.autoExposureSpeed = 1.2f;   // 1 / 秒。1 でおよそ 1 秒で 63% 追い付く
s.sceneLook3D(look);
```

| 項目 | 範囲 | 意味 |
|---|---|---|
| `autoExposureSpeed` | 0 以上 | 追い付く速さ (1 / 秒)。0 で切 |
| `autoExposureRangeEv` | 0 以上 | 露出を動かす幅 (EV、段数)。0 は 3。倍率は 2^-幅 から 2^幅 に収まる |
| `autoExposureBiasEv` | 実数 | 狙いのずらし (EV)。正で明るめ。0 で画面の平均が中間灰 0.18 になる |

`ISceneFx::setTonemapExposure` で渡す露出が基準で、その上に自動の倍率を掛けます。bloom のしきい値、AO、色の仕上げ (LUT) は倍率の影響を受けません。

## 測り方と式

resolve 済みの HDR を 32x32 の格子で読み、1 点ごとの輝度 (Rec.709) を 1/1024 から 64 に頭打ちにして log2 を取り、平均します。空の太陽や光源 1 つが平均を引きずらないための頭打ちです。狙いの EV は `log2(0.18) - 平均 + ずらし` を幅で切った値で、EV を指数で狙いに追わせます。式は `include/mitiru/render/AutoExposureMath.hpp` にあり、試験が GPU の結果をこれと比べます。

- 最初の測定では狙いへ直ちに合わせます。測定が届くまでの数フレームは倍率 1 です。
- 測定は GPU から CPU へ読み戻すので、フレーム数ぶん (2 から 3 フレーム) 遅れて効きます。遅れは毎回同じです。
- 画面の中央を重く見たり、明るい小さな物を無視したりはしません。32x32 の標本は画面全体を同じ重みで見ます。

## 録画・リプレイ

追わせる時間は実時間でなく、ゲームのフレーム番号の差 (1 フレーム = 1/60 秒) で進みます。同じ台本は同じ露出の履歴になり、録画・キャプチャ・VRT の絵が実行ごとに変わりません。状態は描画の側にあり、`GameMemory` にもゲームへの入力にも入りません。ゲームから露出の値を読むことはできません。

別の機械では、GPU の浮動小数点の和の順が違うので、倍率が最後の桁でずれることがあります。画面への提示だけに効くので、ゲームの結果には影響しません。

## 費用

使わないフレームは、パスもコピーも作りません。使うと、全画面の 1 パス (1 画素に出す 1024 回の読み) と 1x1 のコピーが増えます。宣言したゲームは初期化で 1x1 の R32F と読み戻しの枠を作り、宣言しない旧体制のゲームは最初に頼んだフレームで作ります。

## Dawn

描きません。機能表の `auto_exposure` は Dawn を「なし」とし、頼まれた回数を `--render-features` の知らせに数えます。

## 実機で見る手順

`mitiru_host.exe cave_exposure/cave_exposure.dll` を起動します。洞窟の奥から外へ歩き、外へ出た瞬間の白飛びと、1 秒ほどの慣れを見ます。Space で自動露出を切ると、洞窟の中が暗いままになります。HDR 出力 ([HDR_OUTPUT.md](HDR_OUTPUT.md)) のモニターでの見た目は、この開発機が SDR なので測れていません。
