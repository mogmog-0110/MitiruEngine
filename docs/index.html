個人開発プロジェクト

C++ でゲームを動かし、HTML / CSS で画面を作る。

MitiruEngine は、音、画像、AI を使ったゲームやアプリを制作できる軽量な C++ ゲームエンジンです。2D を中心に、最小限の 3D にも対応しています。

はじめる 初心者ガイド ダウンロード

制作例

MitiruEngine で完成させたゲーム

「オスカーのガーデニング」は、まいたリズムを次の小節で返すタイミングゲームです。庭は C++ から直接描画し、会話と結果には HTML / CSS を使用しています。ゲームの全状態は、1 個の struct にまとめています。

題字title

庭の立て札を使った題字表示。

本編play

まいた種が、1 小節かけて判定線へ届きます。

手本demo

拍が合うと花が咲き、結果を本数で示します。

このほかに、ノベルゲーム「ハトを育てよう」、クッキング × ノベル「かえるくれーぷ」、流体シミュレーションを消し方に組み込んだ落ちものパズル「FLUID DROP」が動作しています。作品一覧を見る

概要

動作環境と配布条件

対応 OS Windows 10 / 11（x64）
使用規格 C++20
入力 キーボード / マウス / ゲームパッド（Xbox 系・DualShock 4 など、設定不要）
画面 HTML / CSS（CEF）、または C++ から直接描画
ライセンス 独自ライセンス（使用は自由、改変・再配布は不可）
入手方法 installer.exe / zip ・ GitHub Releases

実装例

小さなコードで動かす

状態を struct に置き、update と draw を記述します。mitiru run で実行できます。

// 矢印キーで動かすだけのゲーム
struct MyGame {
    float x = 600, y = 360;

    void update(Input in, float dt) {
        if (in.down(Key::Right)) x += 320 * dt;
        if (in.down(Key::Left))  x -= 320 * dt;
    }

    void draw(Screen& s) {
        s.fillCircle(x, y, 24, color::Cyan);
    }
};

MITIRU_GAME(MyGame)
# 作成して実行
mitiru new my-game
cd my-game
mitiru run

設計と開発機能

MitiruEngine の特徴

  • C++ と HTML / CSS を併用できます。ゲームの処理を C++ で記述し、メニューや HUD を Web ページと同じ形式で作成できます。画面の作り方を見る
  • 保存した変更を実行中に反映できます。ゲームを動かしたまま、調整を続けられます。
  • 実行状態を数秒前まで巻き戻せます。巻き戻した後に修正し、同じ箇所をもう一度実行できます。詳細を見る
  • 必要な機能を個別のウィンドウで開きます。大きな専用エディタは使用しません。機能一覧を見る
  • ゲーム本体は約 0.2 MB の DLL ひとつです。ソースを公開しており、制作したゲームは商用でも使用できます。

MitiruEngine は、ソースを GitHub で公開している軽量な C++ ゲームエンジンです。
