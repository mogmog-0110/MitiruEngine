MitiruEngine

ヘッダオンリーの C++20 ゲームエンジン

Gameplay は C++ で、UI は CEF (HTML/CSS) で。両者は薄い signal-only bridge で繋がる。

はじめてみる → GitHub で見る

設計の三本柱

01

C++ で gameplay

シーンロジック、状態機械、ノベル VM、物理、AI まで、ゲームの「動き」は C++ で書く。決定論的でプロファイル可能、LLM にもデバッガにも素直。

02

CEF で UI

HUD、メニュー、ダイアログ、トランジションは HTML / CSS で組む。Web のデザイン技術と既存の UI コンポーネントをそのまま活かせる。

03

Signal-only bridge

JS → C++ は「何が起きたか」、C++ → JS は「何を表示すべきか」。bridge を薄く保つことで gameplay state を一カ所に集約する。

サンプル ショーケース

examples/ 配下のサンプルが実機で何を映すかの抜粋。スクリーンショットは継続的にキャプチャされ、差し替えられる。

vn_game_hybrid

ノベル進行とゲームプレイモードの相互遷移。分岐シナリオを C++ VM が駆動する。

cef_overlay

DX12 で描いたシーンの上に CEF の HTML/CSS HUD を重ねる、ハイブリッド構成の最小デモ。

cef_state_bridge

JS → C++ の入力通知と C++ → JS の状態 push。Signal-only bridge が往復している様子を可視化。

parametric_portrait

パラメータ駆動でポートレートのバリエーションを切り替える。アセット差分の最小実例。

主な機能

ヘッダオンリー構成

33 モジュール / 583 ヘッダ。CMake FetchContent で取り込み、単一の INTERFACE ターゲットを link するだけ。

マルチバックエンドグラフィックス

DX11 / DX12 / Vulkan / OpenGL / WebGL / Null を同一の IDevice 抽象で扱う。CI ではハード不要の Null に自動フォールバック。

Tracy プロファイリング

Tracy が組み込み済み。フレーム単位のホットスポット可視化と GPU タイムライン取得を最小限のコードで有効化できる。

Save schema とマイグレーション

JSON ベースの save 仕様と version-up マイグレーション補助 API を同梱。リリース後のセーブデータ互換性を仕組みで担保する。

JSON Schema バリデーション

ノベルスクリプト、i18n、バランステーブル、art bible まで、コンテンツ系データは JSON Schema で検証される。

テストファーストな文化

Catch2 ベースの単体 / 統合テストが 2254 件 green。Playwright と Chrome DevTools MCP で実機検証も自動化。
