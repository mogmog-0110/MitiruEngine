ちょうどいい、C++ ゲームエンジン。

ルールは C++、画面は HTML / CSS。音や画像、AI を使ったゲームやアプリを、小さなコードで楽しく作れる軽量なゲームエンジンです。2D が主役、最小限の 3D も。

▶ はじめる 初心者ガイド ダウンロード

このエンジンで作ったゲーム

機能サンプルではなく、実際に遊べる形まで作ったものです。下は「オスカーのガーデニング」です。まいたリズムを次の小節で返すタイミングゲームで、庭はネイティブ描画、会話と結果は HTML / CSS、ゲームの全状態は 1 個の struct です。

題字title

タイトル画面を置かず、庭の立て札で題を出す。

本編play

まいた種が 1 小節かけて判定線へ届く。

手本demo

拍が合うと花が咲く。結果は点数でなく本数で言う。

ほかに、ノベルゲーム「ハトを育てよう」、クッキング × ノベル「かえるくれーぷ」、流体シミュレーションを消し方に組み込んだ落ちものパズル「FLUID DROP」がこのエンジンで動いています（作品一覧）。

コード

状態を struct に置いて、update と draw を書くだけ。mitiru run ですぐ動きます。

// 矢印キーで動かすだけのゲーム
struct MyGame {
    float x = 600, y = 360;
    void update(Input in, float dt) {
        if (in.down(Key::Right)) x += 320 * dt;
        if (in.down(Key::Left))  x -= 320 * dt;
    }
    void draw(Screen& s) {
        s.fillCircle(x, y, 24, color::Cyan);
    }
};
MITIRU_GAME(MyGame)
# 作って、動かす
mitiru new my-game
cd my-game
mitiru run

特徴

  • ルールは C++、画面は HTML / CSS。メニューや HUD は Web ページと同じ書き方で作れます（画面を作る）。
  • 保存すると、その場で反映されます。手触りを詰めるあいだ、走らせたままで直せます。
  • 数秒前まで巻き戻して、直して、もう一度流せます。バグの再現手順を組み立て直す手間が要りません（くわしく）。
  • 大きなエディタは開きません。道具はひとつにつきひとつの窓、必要なときだけ呼び出します（道具を見る）。
  • ゲーム本体は 0.2 MB ほどの DLL がひとつ。ソースは公開していて、作ったゲームは商用でも自由に使えます。

軽量な C++ ゲームエンジンです。ソースは GitHub で公開しています。
