個人で作っている、軽量な C++ ゲームエンジン

ちょうどいい、C++ ゲームエンジン。

ルールは C++、画面は HTML / CSS。音や画像、AI を使ったゲームやアプリを、小さなコードで楽しく作れる軽量なゲームエンジンです。2D も 3D も。

コードで見る

状態を struct に置いて、update と draw を書くだけ。mitiru run ですぐ動きます。

// 矢印キーで動かすだけのゲーム
struct MyGame {
    float x = 600, y = 360;
    void update(Input in, float dt) {
        if (in.down(Key::Right)) x += 320 * dt;
        if (in.down(Key::Left))  x -= 320 * dt;
    }
    void draw(Screen& s) {
        s.fillCircle(x, y, 24, color::Cyan);
    }
};
MITIRU_GAME(MyGame)
# 作って、動かす
mitiru new my-game
cd my-game
mitiru run

なぜ MitiruEngine?

  • ソース公開・使うのは自由。 ゲーム作りに自由に使えて（商用も可）、中身も読めます。ただしエンジン本体の改変・再配布は不可。
  • 軽量で、すぐ動く。 ゲーム本体は DLL 1 個（約 0.2 MB）。mitiru new → mitiru run で起動します。
  • HTML / CSS で UI が書ける。 メニューや HUD を Web ページと同じ書き方で。手書き JavaScript は不要。画面を作る →
  • 巻き戻し・録画・AI 観測がついてくる。 状態を 1 個の「flat POD」に置くだけで、同じ仕組みからまとめて。くわしく →
  • 必要なものだけ。 巨大なエディタは開きません。道具は 1 つにつき 1 ウィンドウ。道具を見る →
  • 決定論 + リプレイ。 同じ入力なら必ず同じ結果。録画がそのまま回帰テストになります。

何が作れる

  • 2D ゲーム — アクション・パズル・ノベルなど。スプライトやタイルマップを扱えます。
  • 3D 表示 — glTF モデルの読み込みと表示。
  • プロトタイプ / ゲームジャム — 速い起動とホットリロードで、思いついたものをすぐ試せます。
  • プログラミング学習 — C++ で「動くもの」をすぐ作れる、教材としても。
  • ツール / ビジュアライザ — HTML / CSS の UI と C++ のロジックを組み合わせて。

同梱のデモ timetravel_demo で、巻き戻し・AI 観測の挙動を実際に触れます。
