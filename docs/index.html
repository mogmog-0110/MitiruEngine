C++ ゲームエンジン

MitiruEngine

MitiruEngine は、ゲームロジックを C++、メニューや HUD を HTML / CSS で書ける軽量な C++ ゲームエンジンです。2D も 3D も扱えます。全部入りのエディタを持たず、必要な道具だけを個別のウィンドウに表示する設計。決定的な実行（再現性）と壊れにくさを重視しています。

はじめる 初心者ガイド

C++20 ・ Windows ・ MIT ライセンス ・ mitiru new から数分で動きます

できること

ゲーム作りに必要なもの

小〜中規模のゲームに要るものは、ひととおり揃えてあります。使うものだけ取り出して使えます。

🖥️

HTML / CSS で画面を作る

メニューや HUD を、Web と同じ書き方で作れます。CSS のアニメーションもそのまま使えます。

🎮

2D も 3D も

スプライトやタイルマップを使った 2D から、3D モデルの表示まで扱えます。

✨

手応えのある演出

パーティクル・画面の揺れ・一瞬止まる演出などで、操作の手応えを足せます。

🔊

音

効果音や BGM を鳴らせます。

⌨️

コマンドひとつ

mitiru new で作って mitiru run で動かす。エディタは好きなもので構いません。

♻️

書き換えながら動かせる

コードを保存すると、ゲームを止めずにその場で反映されます。

💾

土台がそろっている

セーブ・入力（キーボード／マウス／ゲームパッド）・通信など、よく使う部品が同梱です。

📖

ドキュメントとサンプル

チュートリアルと、そのまま動くサンプルが付いています。読んで真似るところから始められます。

こだわったところ

壊れにくさと、迷わなさ

MitiruEngine が特に重視しているのが、この 2 つ。どちらも開発中ずっと効いてくる部分です。

壊れにくさ同じ入力なら、いつも同じ結果

バグが「たまにしか出ない」のが、一番つらいもの。MitiruEngine は決定的（同じ入力 → 同じ結果）に作られているので、一度起きたことは必ずもう一度起こせます。

巻き戻して、観察できる time-travel

直前のプレイを 1 フレームずつ巻き戻せます。「なぜか HP が 50 になった」を、原因の 1 行まで追えます。

録画して、テストにできる replay-as-test

入力と乱数の種を記録し、同じプレイを完全に再現。リプレイがそのまま回帰テストになります。

迷わなさ必要なものしか、画面に出さない

巨大なエディタの全機能に圧倒されることがありません。1 つの道具 = 1 つの関心事 = 1 つのウィンドウ。要るものだけが、要るときに出ます。

道具は、別のウィンドウに sub-window

デバッグ道具は別の OS ウィンドウで開きます。ゲーム画面は汚れず、スクリーンショットに余計なものが映りません。

止めずに、書き換えられる hot reload

mitiru watch なら、保存するたびに止めず・状態を保ったまま反映。HTML / CSS の編集もすぐ画面に出ます。

部品ごとに、単独で動く per-system

描画だけ・音だけ、と見たい部品を単独で立ち上げ。全体を起動せず、触りたい部分だけを触れます。

はじめてみる

mitiru new から mitiru run まで、触るファイルは C++ と HTML の 2 つだけ。バグ報告も歓迎です。
