ちょうどいい、C++ ゲームエンジン。

ルールは C++、画面は HTML / CSS。音や画像、AI を使ったゲームやアプリを、小さなコードで楽しく作れる軽量なゲームエンジンです。2D が主役、最小限の 3D も。

▶ はじめる 初心者ガイド ダウンロード

動作環境

対応 OSWindows 10 / 11（x64）
言語C++20
入力キーボード / マウス / ゲームパッド（Xbox 系・DualShock 4 等、設定不要）
画面 (UI)HTML / CSS（CEF）または C++ から直接描画
ライセンス独自ライセンス（使用は自由 / 改変・再配布は不可）
入手installer.exe / zip ・ GitHub Releases

コード

状態を struct に置いて、update と draw を書くだけ。mitiru run ですぐ動きます。

// 矢印キーで動かすだけのゲーム
struct MyGame {
    float x = 600, y = 360;
    void update(Input in, float dt) {
        if (in.down(Key::Right)) x += 320 * dt;
        if (in.down(Key::Left))  x -= 320 * dt;
    }
    void draw(Screen& s) {
        s.fillCircle(x, y, 24, color::Cyan);
    }
};
MITIRU_GAME(MyGame)
# 作って、動かす
mitiru new my-game
cd my-game
mitiru run

特徴

ソースは公開していて、作ったゲームは商用でも自由に使えます（エンジン本体の改変・再配布だけはご遠慮ください）。ゲーム本体は 0.2 MB ほどの DLL がひとつ。mitiru new でひな型を作り、mitiru run で動きます。

メニューや HUD は、Web ページと同じ HTML / CSS で書けます。つなぎの JavaScript を手で書く必要はありません。ゲームのルールを書く C++ と、画面のレイアウトを作る HTML / CSS を、それぞれ得意なまま分けて置いておけます（画面を作る）。

作っている途中で「もう少し速く」「もう少しゆっくり」と手触りを詰めたくなったら、コードを保存するだけでその場に反映されます。うまくいかなかった瞬間まで数秒ぶん巻き戻し、直して、同じ操作をそこからもう一度流す、という直し方もできます。バグの再現手順を組み立て直す手間が要りません。セーブやリプレイ、走らせたまま状態を覗く仕組みも、ゲームの状態を「まるごとコピーできる、数値だけのひとかたまり」にしておくと、そこから素直についてきます（くわしく）。

大きなエディタは開きません。使う道具はひとつにつきひとつの窓、ふだんは何も出さず、必要になったものだけ呼び出します（道具を見る）。

作れるもの

アクション、パズル、ノベルといった 2D のゲームが主な守備範囲です。スプライトやタイルマップを扱えます。3D も、glTF のモデルを読み込んで 2D の上にのせるくらいの範囲なら出せます。

起動が速く、コードを保存すればその場で反映されるので、ゲームジャムや思いつきのプロトタイプにも向いています。C++ で「動くもの」がすぐ手元に出るぶん、学習の題材にもなります。HTML / CSS の画面と C++ のロジックを組み合わせれば、ゲーム以外のツールやビジュアライザも作れます。

どれも サンプル集 に実行画面とコード全文を載せています。
