TUTORIAL

赤べこの横スクロールアクションを作る

C++ で、歩く、跳ぶ、敵を踏む、古銭を拾う、ゴールへ進む、という小さなゲームを組み立てます。前半では移動、当たり判定、ステージ、画像、カメラを実装します。後半では、ホットリロード、観察ウィンドウ、巻き戻し、HTML/CSS の HUD を加えます。

完成するゲーム

矢印キーで赤べこを動かし、Space で跳びます。起き上がり小法師は上から踏むと倒せますが、横から触れると押し戻されます。古銭を拾うとカウンタが増え、右端の幟に触れるとクリアです。

赤べこ、小法師、幟、石畳、古銭はスプライトで表示します。空は drawGradientRect で描き、古銭カウンタとクリア表示には HTML/CSS を使います。

完成したコードは examples/beko_run/ にあります。ビルド後、mitiru_host beko_run/beko_run.dll で実行できます。準備が済んでいない場合は、先にインストールを行ってください。構成はコード構成でも確認できます。

毎フレームの処理

エンジンは入力を読み、update で状態を更新し、draw で画面を描きます。この処理を1秒に約60回繰り返します。1秒あたりの描画回数が FPS です。

赤べこの位置と速度、向き、敵、カメラ、古銭の取得状況などは、1個の struct にまとめます。状態には数値と固定長配列を使い、ポインタや std::vector は入れません。この形式は、後述するホットリロード、観察、巻き戻しに使われます。

歩く・跳ぶ

入力から横方向の速度を作る

in.move() は、矢印キー、WASD、ゲームパッドの左スティックを1組の移動入力にまとめます。.x と .y の値は、それぞれ −1 から 1 です。

const float mx = in.move().x;
vx = mx * SPEED;  // SPEED は 330

if (mx < -0.1f) {
    faceLeft = true;
} else if (mx > 0.1f) {
    faceLeft = false;
}

px += vx * dt;

上向きの速度と重力を加える

地面にいる間に Space を押した瞬間だけ、上向きの速度を設定します。画面座標は左上が原点で、y は下へ増えるため、上向きの速度は負の値です。

if (onGround && in.pressed(Key::Space)) {
    vy = -JUMP;  // JUMP は 780
}

vy += GRAV * dt; // GRAV は 2000
py += vy * dt;

足場との衝突を縦、横の順に解く

赤べこと足場を矩形として扱い、重なった場合は、重なった距離だけ赤べこを戻します。縦方向を先に処理すると、上から降りたときに足場の側面との衝突として扱われる問題を避けられます。

// 縦方向
py += vy * dt;
onGround = false;

for (const Plat& p : kPlats) {
    if (hitBox(p.x, p.y, p.w, p.h)) {
        if (vy > 0.0f) {
            py = p.y - PH * 0.5f;
            vy = 0.0f;
            onGround = true;
        } else if (vy < 0.0f) {
            py = p.y + p.h + PH * 0.5f;
            vy = 0.0f;
        }
    }
}

// 横方向
px += vx * dt;

for (const Plat& p : kPlats) {
    if (hitBox(p.x, p.y, p.w, p.h)) {
        if (vx > 0.0f) {
            px = p.x - PW * 0.5f;
        } else if (vx < 0.0f) {
            px = p.x + p.w + PW * 0.5f;
        }
    }
}
input（入力） キー、マウス、ゲームパッドの入力を確認できるサンプルです。

配置と処理を分ける

足場、敵、古銭の位置は数値の配列として level.hpp に置きます。配置を変えるときは数値を編集し、update は配列を順番に処理します。

struct Plat {
    float x, y, w, h;
};

constexpr Plat kPlats[] = {
    {0.0f, GROUND_Y, WORLD_W, 200.0f},
    {620.0f, 430.0f, 180.0f, 24.0f},
    {980.0f, 432.0f, 160.0f, 24.0f},
    {1170.0f, 356.0f, 160.0f, 24.0f},
    {1360.0f, 288.0f, 160.0f, 24.0f},
    {1600.0f, 384.0f, 170.0f, 24.0f},
    {2180.0f, 428.0f, 260.0f, 24.0f},
    {2980.0f, 424.0f, 200.0f, 24.0f},
};

敵は初期位置から左右へ FOE_RANGE の範囲を往復します。赤べこが落下中に上から触れると敵を倒し、横から触れると赤べこを戻します。古銭は取得済みかどうかを固定長の bool 配列で記録します。

if (hitBox(fx, fy, fw, fh)) {
    if (vy > 0.0f && (py + PH * 0.5f) < f.y - kh * 0.35f) {
        f.alive = false;
        vy = -JUMP * 0.6f;
    } else if (hurt <= 0.0f) {
        hurt = 0.8f;
        px += faceLeft ? 96.0f : -96.0f;
        vy = -260.0f;
    }
}

for (int i = 0; i < NCOIN; ++i) {
    if (!coinGot[i] && hitBox(
        kCoins[i].x - COIN_DISP * 0.5f,
        kCoins[i].y - COIN_DISP * 0.5f,
        COIN_DISP,
        COIN_DISP)) {
        coinGot[i] = true;
        ++coins;
    }
}

スプライトを描く

PNG はゲーム開始時に読み込み、drawSprite で描きます。赤べこには4枚の歩行画像があり、地面を移動している間だけ、Timer を使って0.12秒ごとに切り替えます。進行方向は横反転で表し、被弾中は透明度を変えて点滅させます。

if (onGround && std::fabs(vx) > 10.0f) {
    if (walk.every(0.12f, dt)) {
        step = (step + 1) % 4;
    }
}

const render::Texture& tex = kBeko[step];
s.drawSprite(
    tex,
    dstRect,
    whole(tex),
    color::White.withAlpha(a),
    faceLeft
);

画像は可変長データなので、ゲーム状態の struct には入れません。読み込んだ画像は状態の外に置き、状態には数値と固定長配列だけを残します。

sprites 画像の描画、反転、拡大縮小を確認できるサンプルです。

横スクロール

ゲーム内の横幅は3600で、画面幅は1280です。applyCamera に注視点を渡し、赤べこを追う表示にします。描画後は endCamera で画面固定の座標へ戻します。

s.drawGradientRect(
    Rect{0.0f, 0.0f, SCR_W, SCR_H},
    hex(0xBFE0F5),
    hex(0xF3F6FA)
);

s.applyCamera(camX, SCR_H * 0.5f);

// 足場、古銭、敵、赤べこを描く

s.endCamera();

camX は赤べこの x 座標に追従させます。左右の端では、画面がゲーム内領域の外へ出ないよう値を制限します。

camX = clampf(
    px,
    SCR_W * 0.5f,
    WORLD_W - SCR_W * 0.5f
);
camera（追従カメラ） 画面より広い範囲を追従表示するサンプルです。

ファイル構成

#include "game.hpp"

MITIRU_REFLECT(
    BekoRun,
    px, py, vx, vy,
    onGround, coins, cleared
);

MITIRU_REWIND_BUFFER(600);
MITIRU_GAME(BekoRun);

MITIRU_GAME(BekoRun) が BekoRun をゲーム本体として登録します。同じファイルで、観察対象と巻き戻し用の記録数も申告します。

ホットリロードで調整する

mitiru watch または --watch で実行すると、ソースを保存した時点で新しいコードが読み込まれます。位置や古銭の取得数など、実行中の状態は引き継がれます。

ビルドに失敗した場合はエラーが画面に表示され、それまでのコードで実行が続きます。修正して保存すると、新しいコードが読み込まれます。HTML と CSS の変更も保存時に反映され、こちらは再ビルドを必要としません。

観察ウィンドウで状態を確認する

MITIRU_REFLECT にフィールドを列挙し、--inspect を付けて起動すると、その値を別ウィンドウで確認できます。

MITIRU_REFLECT(
    BekoRun,
    px, py, vx, vy,
    onGround, coins, cleared
);

観察用のウィンドウには、入力値、巻き戻し、FPS、音量メーターなどもあります。用途に応じて必要なウィンドウを開きます。

observe（観察） ゲーム状態を観察ウィンドウへ表示するサンプルです。

過去の状態へ戻す

MITIRU_REWIND_BUFFER で記録するフレーム数を指定します。600フレームは約10秒分です。

MITIRU_REWIND_BUFFER(600);

--inspect rewind で起動するとシークバーが表示され、記録済みの状態へ戻せます。

rewind（巻き戻し） 積み上げたブロックの状態を過去へ戻すサンプルです。

3つの機能に共通する状態管理

ホットリロード、観察、巻き戻しでは、ゲームの状態を1個の struct にまとめてエンジンへ預けます。

エンジンは、この struct をまとめてコピーします。コピーを新しいコードへ渡す処理がホットリロード、各フレームのコピーを保存して復元する処理が巻き戻し、現在値を表示する処理が観察です。

このコピーを成立させるため、BekoRun には数値、bool、固定長配列を入れます。ポインタ、std::vector、画像は入れません。

数値、色、処理の変更はホットリロードできます。struct のフィールドを追加、削除、並べ替えした場合は、保存済みデータの形式が変わるため再起動します。

HTML/CSS で HUD を作る

古銭カウンタとクリア表示は、assets/scene.html をゲーム画面へ重ねて表示します。ゲームの処理は C++ に残し、表示を HTML/CSS で構成します。

C++ は hud.set で値を送り、HTML は同じ名前を data-m-text で受け取ります。JavaScript は必要ありません。

void BekoRun::pushHud(Hud hud) const {
    hud.set("view.coins", coins);
    hud.set("view.total", NCOIN);
    hud.set("view.cleared", cleared ? 1 : 0);
}
<div class="coins">
  <img src="sprites/coin.png">
  <span data-m-text="view.coins">0</span>
  /
  <span data-m-text="view.total">0</span>
</div>

<div
  class="clear"
  data-m-class="show: view.cleared > 0">
  <span>クリア！</span>
</div>

data-m-class="show: view.cleared > 0" は、条件が真のときに show クラスを付けます。HTML と CSS の変更も実行中に反映できます。詳細は画面 (HTML / CSS)にあります。

html_hud C++ の値を複数の HTML 表示へ反映するサンプルです。

コード構成

完成版は examples/beko_run/ の5ファイルで構成されています。

level.hpp

画面とゲーム内領域の寸法、重力、移動速度、跳躍速度、足場、敵、古銭の配置を定義します。

sprites.hpp

赤べこ、小法師、幟、石畳、古銭の画像を読み込みます。石畳の繰り返し描画もここに置きます。

game.hpp

BekoRun と敵の状態を定義します。矩形の重なり判定と値の制限に使う関数も含みます。

game.cpp

入力、跳躍、重力、足場との衝突、敵、古銭、ゴール、カメラ、歩行アニメ、描画、HUD への送信を実装します。

beko_run_dll.cpp

MITIRU_REFLECT、MITIRU_REWIND_BUFFER、MITIRU_GAME を記述します。

主な関数

in：入力

in.move() 矢印キー、WASD、左スティックを合成し、各軸 −1〜1 の値を返します。
in.pressed(Key::Space) キーを押したフレームだけ true です。released は離したフレームだけ true です。
in.down(Key::Right) キーを押している間は true です。
in.confirmPressed() Space、Z、Enter、ゲームパッドの A を決定入力として扱います。
in.mouseDown(0)
mouseX()
mouseY()		 マウスボタンと座標を取得します。
in.padDown(Pad::A)
leftStick()		 ゲームパッドのボタンと左スティックを取得します。

hud：表示、音、操作

hud.set("view.coins", coins) HTML へ値を送ります。
hud.play("hit") 効果音を再生します。第2引数で音量を指定できます。
hud.open(Tool::Inspector) 観察ウィンドウなどを開きます。繰り返し呼んでも1回だけ開きます。
hud.screenshot() 現在の画面を画像として保存します。
hud.quit() ゲームを終了します。

s：描画

s.drawSprite(tex, dst, src) 画像の使用範囲を src、描画先を dst で指定します。色と横反転も指定できます。
s.drawRect(rect, color) 矩形を描きます。
s.drawGradientRect(rect, top, bottom) 上から下へ色が変化する矩形を描きます。
s.applyCamera(x, y)
s.endCamera()		 注視点を画面中央へ移す座標変換を開始し、描画後に解除します。
s.drawTextInRect(rect, "文字", color, size, …) 指定した矩形内へ文字列を描きます。
