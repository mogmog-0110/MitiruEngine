配布する

作ったゲームを、人に渡す

完成したゲームは mitiru dist 一発で、そのまま動く配布フォルダになります。ランタイム一式は data/ にまとめ、トップにはダブルクリックで起動する <名前>.exe（コンソール窓は出ません）だけ。受け取った相手は インストール不要で遊べます。

手順

コマンドひとつ

プロジェクトのフォルダで実行します。Release ビルドが走り、dist/<名前>/ に配布物が組み上がります。

1

配布フォルダを作る

bash
mitiru dist            # → dist/<名前>/ (無コンソールの <名前>.exe)
mitiru dist --zip      # zip も一緒に作る
mitiru dist --pack     # assets を 1 ファイルに埋め込んで隠す
mitiru dist --bat      # ログ確認用にコンソール表示の .bat も追加

できあがるのはこんな構成です。トップはランチャーと data/ だけ。相手はこのフォルダ（または zip）を受け取るだけ。

dist/my-game/ (--pack 時)
my-game.exe              # ← ダブルクリックで起動 (コンソール窓なし)
README.txt
data/                    # ランタイム一式 (移動・削除しない)
  mitiru_host.exe        # ゲームを動かすホスト
  launch.mtargs          # 起動引数 (ウィンドウサイズ等)
  my_game/
    my_game.dll          # あなたのゲーム本体 (機械語)
    assets.mtpak         # 画像・HTML・音を 1 ファイルに梱包 (中身は見えない)
  …CEF ランタイム一式      # HTML UI 用 (ネイティブ構成では同梱されない)

--pack を付けないときは、assets/ フォルダのまま同梱されます（中身が見える）。トップの <名前>.exe は data/mitiru_host.exe を呼ぶだけの小さなランチャーです。

＋

中身を見せたくないとき（--pack）

--pack を付けると、assets/ の中身（HTML・CSS・画像・音）を assets.mtpak という 1 つのファイルに梱包し、バラのファイルを配布物から消します。フォルダを覗いても素材が読めない・抜き出せない状態になります。ゲーム本体（.dll）はもともと機械語なので、ソースは出ません。

起動すると、ゲームはこのパックから直接読み込みます（展開ファイルを置きません）。暗号化ではなく難読化です（対応は HTML/CSS/JS・画像・音）。

2

渡す

フォルダごと zip にして配るか、--zip で作った zip をそのまま渡します。相手は展開して <名前>.exe をダブルクリックするだけ。ランタイムを同梱しているので、別途のインストールは要りません。data/ も一緒に渡してください（中身が本体です）。

ウィンドウサイズなど mitiru.toml の設定はランチャーに自動で反映されます。開発中にログを見たいときは --bat でコンソール表示の .bat も追加できます。

配布サイズ

HTML UI を使うかで、大きく変わる

配布物の大きさは、HTML / CSS の UI を使うか（＝Chromium を同梱するか）で決まります。mitiru.toml で [cef] enabled = false にすると、mitiru dist は Chromium を丸ごと外した ネイティブ構成で組みます。

構成mitiru.toml配布サイズ
ネイティブ
（C++ 描画のみ） [cef]
enabled = false 約 30 MB
HTML UI あり
（CEF / Chromium） 既定（指定なし） 約 300 MB

差のぶんは、まるごと Chromium（libcef.dll だけで 211 MB）です。HTML UI を使うときだけ必要で、C++ だけで描くなら丸ごと不要です。詳しい内訳は インストールページのサイズ表にあります。

対応は Windows x64 です。 mitiru dist が組むのは Windows 向けの実行物です。mac / Linux 版は今後対応予定です。
