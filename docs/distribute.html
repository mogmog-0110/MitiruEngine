DISTRIBUTE

配布する

完成したゲームはmitiru dist一発で、そのまま動く配布フォルダになります。ランタイム一式はdata/ にまとめ、トップにはダブルクリックで起動する <名前>.exe（コンソール窓は出ません）だけ。受け取った相手は、インストール不要で遊べます。

コマンドひとつ

プロジェクトのフォルダで実行します。Releaseビルドが走り、dist/<名前>/ に配布物が組み上がります。

  1. プロジェクトのフォルダでmitiru distを実行する。
  2. dist/<名前>/ ができる。トップの <名前>.exeとdata/ がそろう。
  3. フォルダごと（またはzipで）相手に渡す。相手は <名前>.exeをダブルクリックするだけ。

配布フォルダを作る

mitiru dist            # → dist/<名前>/ (無コンソールの <名前>.exe)
mitiru dist --zip      # zip も一緒に作る
mitiru dist --pack     # assets を 1 ファイルに埋め込んで隠す
mitiru dist --bat      # ログ確認用にコンソール表示の .bat も追加

できあがるのはこんな構成です。トップはランチャーとdata/ だけ。相手はこのフォルダ（またはzip）を受け取るだけで遊べます。

# dist/my-game/  (--pack 時)
my-game.exe              # ← ダブルクリックで起動 (コンソール窓なし)
README.txt
data/                    # ランタイム一式 (移動・削除しない)
  mitiru_host.exe        # ゲームを動かすホスト
  launch.mtargs          # 起動引数 (ウィンドウサイズ等)
  my_game/
    my_game.dll          # ゲーム本体 (機械語)
    assets.mtpak         # 画像・HTML・音を 1 ファイルに梱包 (中身は見えない)
  …CEF ランタイム一式      # HTML UI 用 (ネイティブ構成では同梱されない)

--packを付けないときは、assets/ フォルダのまま同梱されます（中身が見える）。トップの <名前>.exeはdata/mitiru_host.exeを呼ぶだけの小さなランチャーです。

渡す

フォルダごとzipにして配るか、--zipで作ったzipをそのまま渡します。相手は展開して <名前>.exeをダブルクリックするだけ。ランタイムを同梱しているので、別途のインストールは要りません。data/ も一緒に渡してください（中身が本体です）。

ウィンドウサイズなどmitiru.tomlの設定はランチャーに自動で反映されます。開発中にログを見たいときは --batでコンソール表示の .batも追加できます。

中身を見せたくないとき

--packを付けると、assets/ の中身（HTML・CSS・画像・音）をassets.mtpakという1つのファイルに梱包し、バラのファイルを配布物から消します。フォルダを覗いても素材が読めない・抜き出せない状態になります。ゲーム本体（.dll）はもともと機械語なので、ソースは出ません。

挙動

起動すると、ゲームはこのパックから直接読み込みます（展開ファイルを置きません）。対応するのはHTML / CSS / JS・画像・音です。

暗号化ではなく難読化です。カジュアルな覗き見を防ぐ目的で、強い秘匿が必要な用途には向きません。

配布サイズ：HTML UIを使うかで変わる

配布物の大きさは、HTML / CSSのUIを使うか（＝Chromiumを同梱するか）で決まります。mitiru.tomlで [cef] enabled = falseにすると、mitiru distはChromiumを丸ごと外した ネイティブ構成で組みます。

ネイティブ C++描画のみ。[cef] enabled = false — 配布サイズ 約30 MB
CEF HTML UIあり（Chromium同梱）。既定（指定なし）— 配布サイズ 約300 MB

差のぶんは、まるごとChromium（libcef.dllだけで211 MB）です。HTML UIを使うときだけ必要で、C++だけで描くなら丸ごと不要です。詳しい内訳は インストールページのサイズ表にあります。

対応はWindows x64です。mitiru distが組むのはWindows向けの実行物です。mac / Linux版は今後対応予定です。
