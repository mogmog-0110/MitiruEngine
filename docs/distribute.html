DISTRIBUTE

ゲームを渡せる形にまとめる

mitiru distを実行すると、完成したゲームをWindowsで起動できる配布フォルダが作られます。受け取った人は、追加のランタイムをインストールせず、トップにある実行ファイルをダブルクリックして遊べます。

ひとつのコマンドで配布物を作成

プロジェクトのフォルダでmitiru distを実行します。Releaseビルドの後、ゲームの実行に必要なファイルがdist/<名前>/へまとめられます。

  1. プロジェクトのフォルダでmitiru distを実行します。
  2. dist/<名前>/に、<名前>.exeとdata/が作られます。
  3. フォルダ全体、またはzipを渡します。受け取った人は<名前>.exeを起動します。

作成時の指定

mitiru dist            # dist/<名前>/ を作成
mitiru dist --zip      # 配布フォルダとzipを作成
mitiru dist --pack     # assetsをひとつのファイルにまとめる
mitiru dist --bat      # ログ確認用の.batを追加

作成されるフォルダ

--packを指定した場合は、次の構成になります。トップの<名前>.exeは、コンソール画面を出さずにdata/mitiru_host.exeを呼び出す小さなランチャーです。

# dist/my-game/
my-game.exe
README.txt
data/
  mitiru_host.exe
  launch.mtargs
  my_game/
    my_game.dll
    assets.mtpak
  …CEFランタイム一式
my-game.exe ダブルクリックでゲームを起動します。コンソール画面は表示しません。
data/mitiru_host.exe ゲームを動かすホストです。
data/launch.mtargs ウィンドウサイズなどの起動引数を保存します。
my_game.dll 機械語に変換されたゲーム本体です。
assets.mtpak 画像、HTML、CSS、JavaScript、音をまとめたファイルです。

data/にはゲーム本体とランタイムが入っています。トップの実行ファイルと一緒に配布し、移動や削除は行いません。

受け取った人の操作

フォルダ全体をzipにするか、--zipで作成したzipを渡します。受け取った人はzipを展開し、<名前>.exeをダブルクリックします。必要なランタイムは配布物に含まれるため、別途インストールする必要はありません。

mitiru.tomlに記録したウィンドウサイズなどの設定は、ランチャーへ自動で反映されます。ログを確認する場合は、--batでコンソール画面を表示する.batも追加できます。

素材をひとつのファイルにまとめる

--packを指定すると、assets/内のHTML、CSS、JavaScript、画像、音をassets.mtpakへまとめ、個別のファイルを配布物から除きます。ゲームは起動時にこのファイルから直接読み込み、展開したファイルを保存しません。

--packを指定しない場合は、assets/がフォルダのまま収録され、各ファイルを確認できます。ゲーム本体の.dllは機械語であり、ソースコードは配布されません。

assets.mtpakは暗号化ではなく難読化です。内容を簡単に閲覧されることを防ぐための機能であり、強い秘匿が必要な用途には適しません。

HTML UIの有無で配布サイズを選ぶ

配布物の大きさは、HTML / CSSによるUIのためにChromiumを収録するかどうかで変わります。mitiru.tomlで[cef] enabled = falseを指定すると、mitiru distはChromiumを含まないネイティブ構成を作成します。

ネイティブ構成 C++による描画のみ。[cef] enabled = falseを指定し、配布サイズは約30 MBです。
CEF構成 HTML UIを使用し、Chromiumを収録します。指定がない場合の構成で、配布サイズは約300 MBです。

約270 MBの差はChromiumによるもので、libcef.dllだけで211 MBあります。HTML UIを使用する場合に必要となり、C++のみで描画する場合は収録されません。詳しい内訳はインストールページのサイズ表にあります。

現在の配布対象はWindows x64です。 mitiru distはWindows向けの実行ファイルを作成します。macOS版とLinux版は今後対応予定です。
