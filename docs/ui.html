HTML / CSS UI

C++ の値を HTML / CSS の画面へ

MitiruEngine では、ゲームの状態と処理を C++ に置き、スコア表示・メニュー・ダイアログを HTML と CSS で作れます。C++ が送った値を data-m-* 属性で受け取るため、接続用の JavaScript は不要です。

構成

C++ から画面へ値を送り、画面から C++ へ操作を通知します。ゲームの状態は C++ 側で管理します。

使用するファイル

HUD やメニューは assets/scene.html に記述します。エンジンがこの HTML をゲーム画面の上に重ねます。C++ の送信処理は、引数に Hud hud を持つ update(Input in, Hud hud, float dt) などから呼び出します。

実行時に読み込むファイル

scene.html の末尾に次の 2 行を置きます。mitiru build を実行すると、mitiru_runtime/ がシーンの隣へコピーされます。

<script src="mitiru_runtime/mitiru_cef_state.js"></script>
<script src="mitiru_runtime/mitiru_bind.js"></script>

値を表示する

C++ と HTML に同じ名前を記述すると、送信した値が対応する要素へ反映されます。

C++

hud.set("view.hud.score", score);
hud.set("view.hud.combo", combo);
hud.set("view.boss.active", true);

HTML

<span data-m-text="view.hud.score">0</span>

<p data-m-tpl="コンボ {view.hud.combo} 連鎖！"></p>

<div data-m-show="view.boss.active">…</div>

data-m-text の要素内に初期値を置くと、C++ から値を受信する前も表示が空になりません。

主な属性

基本的な HUD は data-m-text で作れます。条件表示、CSS の変更、入力、可変リストにも同じ方式を利用できます。

data-m-text 値を要素のテキストとして表示します。
<span data-m-text="view.score">0</span>
data-m-tpl {名前} を値に置き換えます。
<p data-m-tpl="コンボ {view.combo} 連鎖！"></p>
data-m-format comma、kmb、pct、time、int で数値を整形します。
data-m-show
data-m-hide		 条件に応じて要素を表示または非表示にします。比較式と ! による否定も使えます。
data-m-class 条件が成立したときに指定クラスを追加します。
<div data-m-class="danger: view.hp <= 20">…</div>
data-m-style 値を CSS プロパティへ反映します。
<div data-m-style="width: {view.hp.pct}%"></div>
data-m-attr src、title、ARIA 属性などへ値を設定します。
data-m-flash 値が変化した直後に m-flash クラスを一時的に追加します。
data-m-tween 数値の変化を約 0.3 秒で補間して表示します。
data-m-action クリックなどの操作を C++ へ通知します。
data-m-arg data-m-action とともに値を送ります。
data-m-input Enter またはフォーカスアウトで入力値を送ります。IME 変換中は送信しません。
data-m-input-live 入力中の値も 150ms 間隔で送ります。
data-m-repeat <template> を使って可変リストを表示します。詳細はリスト表示で説明します。
data-m-debug 未送信の名前を開発者コンソールへ警告します。
m-flash
m-enter
m-leave		 値の変化、項目の追加、項目の削除に合わせてエンジンが自動で付けるクラスです。

条件に応じて CSS クラスを付ける

<div class="hpbar" data-m-class="danger: view.hp <= 20">…</div>

<style>
  .hpbar.danger {
    color: red;
    animation: blink 1s infinite;
  }
</style>

view.hp が 20 以下になると danger クラスが追加されます。

値を CSS プロパティへ反映する

<div class="bar">
  <div class="fill" data-m-style="width: {view.hp.pct}%"></div>
</div>

hud.set("view.hp.pct", 62) を実行すると、fill の幅が 62% になります。

値の変化を表示に使う

<span data-m-text="view.score"
      data-m-flash="view.score">0</span>

<style>
  .m-flash { animation: pop .3s; }
</style>

<span data-m-text="view.score"
      data-m-tween="view.score">0</span>

操作を C++ へ伝える

ボタンに data-m-action を付けると、操作名が C++ へ届きます。data-m-arg を使えば値も添えられます。

<button data-m-action="start">はじめる</button>
<button data-m-action="select"
        data-m-arg="'hard'">むずかしい</button>

data-m-arg では、引用符付きの値を文字列、数値を数値として送ります。それ以外は状態のパスとして解決されます。input や select に data-m-action を付けた場合は、現在値も渡されます。

if (in.action("start"))
    startGame();

if (in.action("select"))
    chooseDifficulty(/* arg */);

テキスト入力

<input data-m-input="profile.name" placeholder="なまえ">
<input data-m-input="search.q" data-m-input-live>

確定時には input:profile.name という操作名と入力値が届きます。

if (in.action("input:profile.name"))
    setName(in.actionPayload("input:profile.name"));

可変リストを表示する

手札、インベントリ、ランキングなどは data-m-repeat と <template> で表示できます。要素は再利用されます。

<div class="hand" data-m-repeat="view.hand">
  <template>
    <div class="card"
         data-m-action="play"
         data-m-arg="i">
      <span data-m-text="cost"></span>
      <span data-m-text="name"></span>
    </div>
  </template>
</div>

リスト内では、項目のフィールドを data-m-text="name" のように直接指定します。C++ 側では StateWriter の array() または list() で組み立て、hud.set で送ります。詳細は機能リファレンスの HTML / CSS 画面にあります。

区切り形式で送る

毎フレーム更新する弾、敵、コインなどは、"2,80,120;1,300,60" のような区切り形式でも送れます。HTML 側では data-m-fields で各列に名前を付けます。

<div class="field"
     data-m-repeat="view.scene"
     data-m-fields="t,x,y">
  <template data-m-case="1">
    <div class="coin" data-m-pos="x,y"></div>
  </template>
  <template data-m-case="2">
    <div class="enemy" data-m-pos="x,y"></div>
  </template>
</div>

data-m-case は種類に応じてテンプレートを選びます。種類に使う列は既定で t です。data-m-pos は座標を transform: translate(x,y) へ変換します。

並べ替えを CSS transition へつなぐ

<ol class="rank"
    data-m-repeat="view.rank"
    data-m-key="id"
    data-m-leave>
  <template>
    <li class="row"
        data-m-tpl="{name} — {score}"></li>
  </template>
</ol>

<style>
  .rank .row {
    transition: transform .3s;
  }
  .rank .row.m-enter {
    opacity: 0;
  }
  .rank .row.m-leave {
    animation: fadeout .3s forwards;
  }
</style>

data-m-key を指定すると、項目は順番ではなくキーで保持されます。順位の変更時も要素が再作成されないため、CSS transition を利用できます。

リスト用の属性

data-m-fields区切り形式の列名を指定します。
data-m-sep
data-m-fsep		項目と列の区切りを変更します。既定値は ; と , です。
data-m-typeテンプレート選択に使う列名を変更します。既定値は t です。
data-m-case指定した種類の項目に使うテンプレートを選びます。
data-m-key項目を指定フィールドの値で保持します。
data-m-pos2 つのフィールドを要素の移動量へ変換します。
data-m-rot要素へ回転角を設定します。
data-m-leave削除前に m-leave を付け、CSS アニメの終了後、最長 400ms で要素を削除します。
m-enter生成直後の要素へ一時的に付くクラスです。

実装例

「はじめてのゲーム」で使用している assets/scene.html の例です。C++ から view.coins、view.total、view.cleared を送り、HTML で受け取ります。接続用の JavaScriptは記述していません。

<html lang="ja">
<head>

      font-family: sans-serif;
    }

    .coins {

      top: 14px;
      left: 16px;

      color: #7a5320;
      font-weight: 700;
      font-size: 22px;
    }

    .coins img {
      width: 26px;
      height: 26px;
    }

    .clear {
      position: absolute;
      inset: 0;
      opacity: 0;
      display: flex;

      background: rgba(20,20,30,0);

    }

    .clear.show {
      background: rgba(20,20,30,.42);

  <script src="mitiru_runtime/mitiru_bind.js"></script>

C++ 側では、表示に使う値を次のように送ります。

void BekoRun::pushHud(Hud hud) const {
    hud.set("view.coins", coins);
    hud.set("view.total", NCOIN);
    hud.set("view.cleared", cleared ? 1 : 0);
}

画面の見た目には、影、角丸、@keyframes、backdrop-filter など、ブラウザで利用できる CSS を使えます。必要であれば JavaScript も記述できます。

確認方法

C++ が送っていない名前を HTML で指定してもエラーにはならず、要素内の初期値が残ります。値が更新されない場合は、次を確認します。

  • C++ の hud.set と HTML の data-m-* で、名前が完全に一致しているか。
  • 値を受信していても、CSS によって要素が見えない状態になっていないか。

mitiru lint を実行すると、HTML で参照している名前と C++ から送っている名前を照合できます。実行中は <body data-m-debug> を付けるか、シーンを ?mdebug=1 で開くと、未送信の名前が開発者コンソールへ表示されます。

data-m-* だけでも HUD を構成できます。さらに処理が必要な場合は JavaScript も追加できます。

はじめてのゲームで基本的な制作手順を確認できます。属性の詳細は機能リファレンスの HTML / CSS 画面にも掲載しています。
