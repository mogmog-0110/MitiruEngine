AI 連携

AI が実行結果まで確かめられる

MitiruEngine では、Claude Code や Codex などの AI エージェントが、実行中のゲームを観測・操作できます。画面・状態・音を取得し、修正後の結果を mitiru verify で検証できます。

できること

  • 状態を読む：ゲームの全状態を JSON で取得し、フレーム間の差分も確認できます。
  • 画面を読む：描画の種類、位置、文字の内容を一覧で取得できます。
  • 音を読む：効果音や BGM の再生・停止、音量、高さを取得できます。
  • 実行を操作する：入力、停止、コマ送り、速度変更、巻き戻しができます。
  • 修正結果を検証する：mitiru verify がビルド、起動、観測、判定を実行します。

AI エージェントによる確認の流れ

コードを修正する
mitiru verify
GET /api/ai/frame
GET /api/ai/state
GET /api/ai/diff
mitiru verify --replay play.mtrr

mitiru verify は、結果を JSON と終了コードで返します。画面や状態を取得できるため、人が実行画面を見て伝えなくても、AI エージェントが結果を確認できます。

有効化

環境変数 MITIRU_AI=1 を設定して起動します。ゲーム側のコード変更は不要です。HTTP API は既定で 127.0.0.1:8090 に開き、ポートは MITIRU_AI_PORT で変更できます。通常の起動時には開きません。

set MITIRU_AI=1
mitiru run

# stderr:
# [ai] HTTP API listening on 127.0.0.1:8090

画面を読む

GET /api/ai/frame は、そのフレームで実行された描画の種類、位置、寸法、文字の内容を返します。縮小した PNG も同じ応答に含まれ、?screenshot=0 で省略できます。

{"frameNumber":8652,"screen":{"width":1280,"height":720},
 "drawCalls":[
   {"call":"drawRect",  "x":24, "y":24, "w":360,   "h":22},
   {"call":"drawRect",  "x":24, "y":24, "w":284.4, "h":22},
   {"call":"drawText",  "x":398,"y":22, "w":110,   "h":22, "text":"HP 79"},
   {"call":"drawCircle","x":618,"y":338,"w":44,    "h":44},
   ...
 ],
 "screenshot":{"width":640,"height":360,"pngBase64":"..."}}

この例では、幅 360 の外枠に対して中身の幅が 284.4 なので、残りが 79% だと画像処理なしで確認できます。PNG には HTML / CSS の HUD も合成されます。

最初の呼び出しで記録が始まり、内容は次のフレームから取得できます。音は GET /api/ai/audio で取得できます。

状態を読む

ゲームの全状態は、まとめてコピーできる一つの領域に置かれます。MITIRU_REFLECT で公開するフィールドを指定すると、現在の状態を JSON で取得できます。

GET /api/ai/state
# {"hearts":3,"pos_x":32.0,"scene":0,...}

GET /api/ai/diff?from=0&to=60
# 2 フレーム間で変化した値

POST /api/ai/branch
# 現在の状態から別の入力を試す

画面に表示された値と内部状態を別々に取得できるため、表示と値の不一致も確認できます。

修正結果を検証する

mitiru verify は、ビルド、起動、観測、判定を一つのコマンドで実行します。結果は JSON と終了コードで返され、CI でも利用できます。

mitiru verify
# ビルド、起動、スクリーンショット取得

mitiru verify --golden ref.png
# 基準画像との比較

mitiru verify --replay play.mtrr
# 記録した操作の再現

# {"build":"ok","verdict":"pass",...}
# 終了コード: 0=pass / 1=fail / 2=build error

基準画像との比較では見た目を確認し、リプレイでは同じ入力による結果をバイト単位で判定します。

Claude Code から使う

mitiru mcp は、AI 連携 API を MCP（Model Context Protocol）経由で公開します。プロジェクトの .mcp.json に次の設定を追加します。

{"mcpServers": {"mitiru": {"command": "mitiru", "args": ["mcp"]}}}

game_state、frame、screenshot、simulate_input、pause、step、verify などを利用できます。AI エージェントはゲームを操作し、コマ送りで観測して、結果を判定できます。

主な API

観測

GET /api/ai/frame描画の種類、位置、文字の内容、縮小 PNG
GET /api/ai/stateゲームの全状態を表す JSON
GET /api/ai/diff?from=&to=2 フレーム間の状態差分
GET /api/ai/audio?max=N効果音と BGM の再生、停止、音量、高さ
GET /api/ai/ringsize記録済みのフレーム数
POST /api/ai/branch現在の状態から別の入力で N フレーム実行
GET /api/screenshotHTML の HUD を合成した画面 PNG
GET /api/healthフレーム番号と経過時間

実行制御

POST /api/input/simulate外部から入力する
POST /api/runtime/pause停止状態を切り替える
POST /api/runtime/step1 フレーム進める
POST /api/runtime/timescale実行速度を変更する
POST /api/runtime/resim指定したフレーム数だけ戻り、記録済みの入力で再生する
POST /api/runtime/lofi低解像度・減色の演出を切り替える
POST /api/runtime/quitゲームを終了する
GET /api/runtime/status停止状態、速度、現在のフレームを取得する

検査

GET /api/observe/schema観測データの JSON Schema
GET /api/observe/inspect?prefix=観測値の一覧
GET /api/observe/inspect/at?back=NN 個前のスナップショット
GET /api/observe/inspect/depth記録履歴の深さと容量
GET /api/scene・GET /api/scene/treeシーン全体とシーンツリー
GET /api/render/stats描画の統計
GET /api/debug/log・GET /api/debug/errors直近のログとエラー
GET /api/status・GET /api/configゲームエンジンの状態と設定
GET /api/project/infoプロジェクト情報
GET /api/flags・POST /api/flagデバッグ用スイッチの取得と変更

ブラウザ操作盤とシーン編集

GET /consoleブラウザ操作盤を開く
GET /api/commands[/カテゴリ]実行可能なコマンドの一覧
POST /api/commandコマンドを実行する
POST /api/game/run・POST /api/game/stopゲームを起動・停止する
POST /api/scene/create-node・save・loadノード作成、シーン保存、読込
PUT・DELETE /api/scene/node/<id>ノードの更新・削除と trait の追加・削除
GET /api/editor/state ほかエディタの視点、選択、注視、スクリーンショット

詳しい手順は、リポジトリの docs/AI_WORKFLOW.md にあります。

この機能を支える設計

  • ゲームの全状態をまとめてコピーできるため、JSON への変換、差分取得、巻き戻し、分岐実行、リプレイを同じ状態データに対する処理として実装できます。
  • 同じ入力から同じ結果を得られるため、記録した操作を回帰テストに利用できます。
  • HUD に HTML / CSS を使い、スクリーンショットへ UI を合成できます。

巻き戻しとリプレイについては、機能リファレンス で説明しています。
